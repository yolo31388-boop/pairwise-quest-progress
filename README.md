# pairwise-quest-progress

组队击杀计数只算最后一击，任务进度按个人伤害归属，辅助玩家打了 90% 血却零进度；同一只怪被两个队伍同时打，掉落和计数都发了两份；任务进度存在客户端，断线重连后回到旧值；每日任务重置按本地时区，跨时区组队时有人先重置；任务链前置条件只查最终状态，跳过中间步骤的玩家卡在下一步；重复的击杀事件因为网络重传被计两次，进度直接超额；服务器回滚战斗结果后任务进度没有一起回滚；离线玩家的任务进度在登录时批量结算，顺序错了导致后续任务无法接取；UI 缓存了进度文本，服务器更新后界面还显示旧数字；任务完成奖励发放与进度写入不在同一事务，进度满了但奖励丢失。gameplay/quest_progress.py 是核心，tests/test_quest_progress.py 15个红。要修的是：按伤害贡献分配；实例归属去重；进度服务器权威；重置按服务器时区；前置按步骤链；事件幂等；回滚同步进度；离线按时间序结算；UI 订阅变更；奖励同事务。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
